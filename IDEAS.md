# Ideas / wishlist

Parked enhancements for the portfolio. Nothing here is started yet — it's a
backlog to pick from whenever. No deadlines.

## Cheap wins (plain CSS/JS, no rewrite)

These are polish, not plumbing. Each is small and self-contained.

- **Scroll-reveal** — sections fade/slide in as they come into view instead of
  appearing all at once.
- **Smoother hover micro-interactions** — more refined hover states on cards,
  buttons, and menu items (subtle lifts, glows, transitions).
- **Refined spacing & typography scale** — tighten the consistent rhythm of
  font sizes and gaps across the site.
- **Light / dark toggle** — a switch so visitors can flip between the current
  dark theme and a light one.
- **Section transitions** — a short animated transition when switching between
  menu sections (Home, Projects, etc.) instead of an instant swap.

## Bigger swings (more effort, think first)

- **3D background (Three.js)** — replace the current 2D canvas starfield with a
  real 3D scene. Flashier, but heavier and slower on phones. The current
  starfield already looks good and runs fast everywhere, so weigh this one
  before committing.

## Maybe someday

- Migrate to a framework (Astro / Svelte / Next) only if the site grows into
  multiple pages. Overkill for a single-page portfolio today.
